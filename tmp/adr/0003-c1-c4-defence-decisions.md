# C1/C4 defence decisions from the methodology review

We stress-tested the project against the C1 rubric (KDH1–KDH5) and the app concept
against C4 (KOM1–KOM5) before writing any report prose. Five C1 answers and one
attachment rule were settled in a grilling session on 2026-09-15 and are recorded
in the report pack (`7-q-and-a-defence.md`, `6-impact-app-concept.md`).

## Decisions

- **SDG anchor**: SDG 8.9 primary (sustainable tourism policies), SDG 17.18 supporting
  (better measurement enables better policy). One sentence each; stated in the report,
  not implied.
- **2019 anchor**: official pre-crisis baseline, framed as a measuring stick for the
  stagnation line — not a target to revert to.
- **k=4 segmentation**: justified by policy mapping (four segments → four
  prescriptions), not by a statistical criterion; optional silhouette sweep only if a
  spare hour exists, reported honestly either way.
- **Declared limitation**: the Missing Billions counterfactual uses the national
  average per-visitor yield, so it combines within-market yield change with market-mix
  change; written into `report-pack/2-method-notes.md` §2.4 rather than left for a
  judge to find. Full decomposition is future work, not deadline work.
- **App concept**: attaches to C4 as an implementation model (judges score the model,
  not a built product); the analysis headline (Missing Billions, Volume Trap) stays the
  headline. Details in `report-pack/6-impact-app-concept.md`.

## Rejected

- Pivoting the project to the app (loses C1/C2 evidence; app alone scores only C4).
- A vendor-level "businesses with an app earn more" evidence base (selection bias;
  vendor revenue is not national tourism yield).
- A nominal-counterfactual decomposition or a trend-based anchor before the deadline.
